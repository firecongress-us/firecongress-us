# FireCongress.us

Non-partisan civic accountability reporting. Documenting members of Congress — from both parties — who demonstrate conflicts of interest, corporate capture, or failure to represent their constituents.

## Stack

- [Astro 6](https://astro.build) — static site generator
- [Tailwind CSS v4](https://tailwindcss.com) — styling
- Hosted on [Vercel](https://vercel.com)

## Content Agent

Twice-weekly research posts are generated by a scheduled Claude Code agent running on a local Pi. Drafts are submitted as PRs for human review before merging to production.

## Commands

| Command         | Action                                      |
| :-------------- | :------------------------------------------ |
| `npm install`   | Install dependencies                        |
| `npm run dev`   | Start local dev server at `localhost:4321`  |
| `npm run build` | Build production site to `./dist/`          |
